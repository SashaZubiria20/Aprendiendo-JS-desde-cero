# Aprendiendo JavaScript desde Cero

¡Hola! Este es mi repositorio personal donde documento mi proceso de aprendizaje en **JavaScript**. Aquí guardo todos los ejercicios prácticos, retos y apuntes que voy realizando en mi curso de Udemy.

## 📂 Contenido del Repositorio

He dividido mi aprendizaje en bloques lógicos para dominar las bases del lenguaje:

### 1️⃣ Fundamentos y Sintaxis
*   **Sintaxis Básica:** Reglas de escritura, uso de `;` y Case Sensitivity.
*   **Variables y Constantes:** Declaración y uso de `let` y `const`.
*   **Tipos de Datos:** Primitivos (Strings, Numbers, Booleans) y Operadores (Matemáticos, asignación, incrementos).

### 2️⃣ Herramientas Nativas
*   **Strings:** Manipulación de textos con la propiedad `.length` y métodos avanzados (`trim`, `slice`, `toUpperCase`, `toLowerCase`, etc.).
*   **Objeto Math:** Operaciones matemáticas complejas (potencias, raíces, redondeos y generación de números aleatorios).

### 3️⃣ Estructuras de Control y Lógica
*   **Condicionales:** Toma de decisiones con `if / else`, `switch` y el `Operador Ternario`.
*   **Bucles (Loops):** Repetición de tareas con `while`, `do-while`, `for`, `for-of` (para valores) y `for-in` (para índices).

### 4️⃣ Estructuras de Datos Complejas
*   **Arrays:** Colecciones de datos, índices, propiedad `.length` y métodos de manipulación (`push`, `pop`, `splice`, `join`, etc.).
*   **Objetos:** Estructuras clave-valor para representar entidades del mundo real y arrays de objetos.

### 5️⃣ Modularización
*   **Funciones:** Creación de bloques de código reutilizables, parámetros, retorno de valores y diferencia entre funciones tradicionales y **Arrow Functions**.

## 🛠️ Cómo ver los ejercicios

Para visualizar la ejecución del código y los resultados en la consola:
1.  Abre el archivo `index.html` en tu navegador.
2.  En el código del `index.html`, **descomenta** el `<script>` del tema que desees revisar.
3.  Abre la consola de desarrollador presionando `F12` o `Click derecho > Inspeccionar > Consola`.
