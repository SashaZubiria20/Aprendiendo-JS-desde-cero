# Aprendiendo JavaScript desde Cero

¡Hola! Este es mi repositorio personal donde guardo todos mis avances, ejercicios y retos del lenguaje **JavaScript**. 

Aquí documento mi proceso de aprendizaje, desde las bases hasta conceptos más avanzados.

## 📂 Contenido del Repositorio

En este proyecto encontrarás ejercicios prácticos sobre:

*   **Sintaxis básica:** Variables (`let`, `const`), tipos de datos y operadores.
*   **Estructuras de control:** Condicionales (`if`, `switch`, ternarios).
*   **Bucles:** `while`, `do-while`, `for`, `for-of`, `for-in`.
*   **Arrays:** Métodos de manipulación y recorrido de arreglos.
*   **Objetos:** (Próximamente...)

## 🛠️ Cómo ver los ejercicios

Para ver los resultados en la consola del navegador:
1. Abre el archivo `index.html`.
2. Descomenta el `<script>` del tema que quieras revisar.
3. Abre la consola de desarrollador (`F12`).
